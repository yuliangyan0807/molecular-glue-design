# molecular-glue-design


## Datasets

This project utilizes the following datasets:

- **TernaryDB**: Molecular glue complexes from the TernaryDB dataset, which contains ternary protein-protein-ligand complexes involving molecular glues.

- **PDBBind**: Protein-protein interaction datasets from [PDBBind-Plus](https://www.pdbbind-plus.org.cn/download), which provides comprehensive protein-protein binding data for training and validation.

These datasets are essential for training our molecular glue design models and evaluations.
